=====================================================
  EXCERPTA — Extrator de Artigos Científicos em PDF
=====================================================

REQUISITO: Python 3.9 ou superior
  • Windows: https://python.org/downloads
    (marque "Add Python to PATH" na instalação)
  • Linux/Mac: normalmente já vem instalado


ANTES DA PRIMEIRA VEZ (só no Windows)
─────────────────────────────────────
Dê duplo clique em "Instalar dependências (Windows 11).bat".
Ele prepara o computador: instala o Python, se faltar, e as bibliotecas
necessárias. Ele NÃO abre o programa, e só precisa rodar uma vez.

No Linux/Mac não há esta etapa — o próprio iniciar.py resolve tudo.


COMO ABRIR O EXCERPTA
─────────────────────
Sempre pelo arquivo "iniciar.py", em qualquer sistema:

  Windows:    duplo clique em iniciar.py
  Linux/Mac:  abra o terminal nesta pasta e execute:
                python3 iniciar.py

Se faltar alguma dependência, o iniciar.py instala antes de abrir. Nenhuma
instalação requer permissão de administrador (~50 MB no total: pymupdf4llm,
customtkinter, tkinterdnd2).

Suporte a OCR (docling, ~2 GB, 10–20 min, necessário só para PDFs escaneados
sem texto nativo) e IA local (Ollama, opcional) NÃO são instalados nesta
etapa — instale quando precisar dentro do próprio Excerpta, em
"⚙ Configurações".


COMO USAR
─────────
O Excerpta extrai seções de artigos científicos em PDF.

  1. Selecione a pasta com os PDFs
  2. Os artigos da pasta são carregados automaticamente
  3. Escolha quais seções extrair (abstract, métodos, resultados…)
     ou deixe "Artigo completo" marcado
  4. Clique em "Extrair artigos"
  5. Salve o arquivo de texto gerado

Você também pode arrastar PDFs soltos para a lista de artigos.


USAR COM O ZOTERO (opcional)
────────────────────────────
Se o Zotero estiver aberto, o Excerpta mostra a coleção que você tem
selecionada nele e importa os PDFs dela com um clique.

  • Coleção inteira: selecione a coleção no Zotero. A linha "Zotero" no
    Excerpta mostra o nome e a quantidade — clique em "Importar PDFs".

  • Alguns artigos só: selecione-os no Zotero (Ctrl+clique) e arraste
    para a lista de artigos do Excerpta.

Requisito: no Zotero, em Editar → Configurações → Avançado, marque
"Allow other applications on this computer to communicate with Zotero".
Sem isso o Excerpta mostra "Zotero não conectado".

O Excerpta só lê a biblioteca do Zotero — nunca altera nada nela.
Artigos sem PDF anexado, ou cujo PDF ainda não foi baixado para este
computador, são informados ao fim da importação.


DÚVIDAS / PROBLEMAS
────────────────────
• Windows: se o instalador disser que não localizou o Python logo após
  instalá-lo, feche a janela e execute o .bat de novo — na segunda vez ele
  encontra. Reiniciar o computador não é necessário.
• Em caso de erro de permissão no Linux, tente:
    pip install pymupdf4llm customtkinter tkinterdnd2 --break-system-packages
